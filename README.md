# Fitapp

Фитнес-приложение на Expo (React Native) с 3D-интерфейсом на Three.js и `@react-three/fiber/native`.

## Возможности

- **Сегодня**: 3D-кольца активности по журналу тренировок (калории, минуты), журнал за день, вес для расчёта калорий.
- **Упражнения**: 25 упражнений по группам мышц (плечи, грудь, спина, руки, ноги, пресс, кардио) и 4 готовые программы.
  - 3D-манекен показывает технику анимацией и подсвечивает мышцы: красным основные, оранжевым вспомогательные.
  - Техника по шагам и частые ошибки.
  - Счётчик подходов: повторы или время, таймер отдыха, вес гантели.
  - После упражнения показывается расход калорий, запись добавляется в журнал.
- **Таймеры**:
  - Бег: секундомер с кругами, дистанция и калории по выбранному темпу.
  - Кардио-интервалы: Tabata, HIIT или свои настройки работы, отдыха и раундов; 3D-кольцо фазы, вибрация при смене фазы.
- **Прогресс**: 3D-столбцы за неделю.

Калории считаются по формуле MET × вес (кг) × часы. Журнал и вес сохраняются на устройстве (AsyncStorage).
Шаги и прошлые дни недели пока демонстрационные.

## Запуск

```bash
npm install
npx expo start        # QR-код для Expo Go
npx expo start --web  # в браузере
```

Проверки: `npx tsc --noEmit` и `npm run lint`.

## Структура

- `App.tsx`: таб-бар и экран упражнения (модальное окно)
- `src/screens/`: экраны
- `src/three/`: 3D-сцены; `Mannequin.tsx` и `poses.ts` отвечают за манекен и позы упражнений
- `src/data/`: упражнения, программы, демо-данные недели
- `src/store.tsx`: журнал тренировок и вес
- `src/calories.ts`: расчёт калорий и форматирование времени
