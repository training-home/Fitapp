# Fitapp

Фитнес-приложение на Expo (React Native) с 3D-интерфейсом на Three.js и `@react-three/fiber/native`.

## Экраны

- **Сегодня**: объёмные кольца активности (калории, минуты тренировки, шаги) вокруг пульсирующего ядра.
- **Тренировки**: 3D-модель инвентаря (гантель, гиря, скакалка, коврик) меняется вместе с выбранной тренировкой.
- **Прогресс**: 3D-столбцы активности за неделю с выбором дня.

Каждую сцену можно вращать пальцем, после отпускания она крутится по инерции.

## Запуск

```bash
npm install
npx expo start        # QR-код для Expo Go / dev build
npx expo start --web  # в браузере
```

## Структура

- `App.tsx`: таб-бар и переключение экранов
- `src/screens/`: экраны
- `src/three/`: 3D-сцены (`Scene3D` содержит Canvas, свет и вращение жестом)
- `src/data.ts`: демо-данные (пока без бэкенда)
